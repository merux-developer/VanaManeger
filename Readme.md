# ヴァナ・マネージャー

FFXI（ファイナルファンタジーXI）プレイヤー向けの非公式冒険支援Androidアプリです。

ヴァナ・ディールでの日々の活動をスマートフォンで管理できるように設計されており、預かり帳、青魔法、アタッチメント、各種コンテンツタイマーなどを一括で管理できます。

> ※本アプリはファン制作の非公式ツールです。株式会社スクウェア・エニックスとは一切関係ありません。

---

主な機能

・預かり帳管理
・自作リスト
・コンテンツタイマー
・青魔法管理
・アタッチメント管理
・フェイス管理(v1.1.0)
・ボナンザ管理(v1.1.0)

---

## インストール方法

1. GitHub Releasesから最新版APKをダウンロード
2. APKファイルを開く
3. Androidの案内に従ってインストール

### 初回インストール時

Androidの仕様により「不明なアプリ」として警告が表示される場合があります。

その場合は許可してインストールを続行してください。

---

## アップデート時の注意

アプリ更新前には必ずバックアップを作成することを推奨します。

**推奨手順**

1. 設定 → バックアップ
2. JSONファイルを保存
3. Google DriveやPCへ保管
4. APKを更新
5. 必要に応じてリストア

---

## 使用方法

### 初回起動

1. アプリを起動
2. キャラクターを追加
3. 管理したい項目を選択

### キャラクター画面

各キャラクターごとに以下を管理できます。

* 預かり帳
* 自作リスト
* コンテンツタイマー
* 青魔法
* アタッチメント
