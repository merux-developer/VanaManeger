# ヴァナ・マネージャー

FFXI（ファイナルファンタジーXI）プレイヤー向けの非公式冒険支援Androidアプリです。

ヴァナ・ディールでの日々の活動をスマートフォンで管理できるように設計されており、預かり帳、青魔法、アタッチメント、各種コンテンツタイマーなどを一括で管理できます。

> ※本アプリはファン制作の非公式ツールです。株式会社スクウェア・エニックスとは一切関係ありません。

---

## 主な機能

### 📦 預かり帳管理

* 預かり帳の装備保管状況を管理
* チェックリスト形式で確認可能
* 預かり帳【01】～【33】対応
* 今後追加される装備を手動登録可能

### 📝 自作リスト

* 「欲しい装備リスト」
* 「作成予定リスト」
* 「目標装備リスト」

など、自由なリストを作成・管理できます。

### ⏱ コンテンツタイマー

* 再突入時間を管理
* カウントダウン表示
* 通知機能対応
* NMリポップ時間など自由なタイマー作成可能
* 初期登録済みコンテンツの時間編集可能

### 🔵 青魔法管理

* ラーニング状況の管理
* BP（ブルーポイント）自動計算
* 魔法セット構成の保存
* 習得済み魔法のみセット可能

### 🤖 アタッチメント管理

* 所持状況の管理
* 属性値自動計算
* 構成案の保存
* 所持済みアタッチメントのみセット可能

### 👤 キャラクター管理

* 複数キャラクター登録
* キャラクターごとに個別データ管理
* 簡単切り替え対応

---

## 設定機能

### テーマ変更

* ライトモード
* ダークモード

など、お好みの表示に変更できます。

### 表示形式変更

預かり帳の表示方法を選択できます。

* 見出し形式
* カテゴリ選択形式

### 通知設定

コンテンツタイマー終了時の通知をON/OFFできます。

### バックアップ

アプリ内データをJSON形式で保存します。

機種変更やアップデート前にはバックアップを推奨します。

### リストア

保存済みバックアップファイルからデータを復元できます。

---

## インストール方法

1. GitHub Releasesから最新版APKをダウンロード
2. APKファイルを開く
3. Androidの案内に従ってインストール

### 初回インストール時

Androidの仕様により「不明なアプリ」として警告が表示される場合があります。

その場合は許可してインストールを続行してください。

---

## アップデート時の注意

アプリ更新前には必ずバックアップを作成することを推奨します。

**推奨手順**

1. 設定 → バックアップ
2. JSONファイルを保存
3. Google DriveやPCへ保管
4. APKを更新
5. 必要に応じてリストア

---

## 使用方法

### 初回起動

1. アプリを起動
2. キャラクターを追加
3. 管理したい項目を選択

### キャラクター画面

各キャラクターごとに以下を管理できます。

* 預かり帳
* 自作リスト
* コンテンツタイマー
* 青魔法
* アタッチメント
